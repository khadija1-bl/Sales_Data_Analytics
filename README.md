
# Sales Data Analytics

## Description
Ce projet consiste à analyser les données de ventes afin de suivre les performances commerciales et calculer le chiffre d'affaires.

## Technologies utilisées
- Python
- Pandas
- MySQL
- Power BI

## Structure du projet
- data : fichiers CSV
- python : script de traitement des données
- sql : script de création de la base de données
- power bi : tableau de bord interactif

## Traitement des données
- Lecture du fichier CSV
- Vérification des valeurs manquantes
- Détection des doublons
- Conversion des dates
- Calcul du chiffre d'affaires
- Analyse des ventes par ville et par produit
- Exportation des données nettoyées

## Tableau de bord
Le dashboard Power BI présente :
- Le chiffre d'affaires total
- Le chiffre d'affaires par ville
- Les quantités vendues par produit
- Le chiffre d'affaires par catégorie

## Résultat
Chiffre d'affaires total : 66 460 DH
